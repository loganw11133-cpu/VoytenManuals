Eaton VCP-W Decoder

Medium Voltage Vacuum Circuit Breaker — Type & Style Number Identification
Unlike a low-voltage catalog number, a VCP-W type is not decoded character by character — the type space is a closed set, so this looks it up and returns the published rated values. Enter the type (callout A on the nameplate) for ratings and weights, or the 10-digit style number (callout D) to work back to the type, continuous current and control voltage. Spacing and hyphen position do not matter.
